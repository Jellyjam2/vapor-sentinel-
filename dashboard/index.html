GET STARTED

From signal to insight.

Run Vapor Sentinel from your repository folder, then open the resulting recording here.

Record this machine

cargo run --locked -- --samples 20 --output evidence.jsonl

Explore a repeatable replay

cargo run --locked -- --replay tests/fixtures/memory-sequence.json --output evidence.jsonl

Replay always disables webhook actions. Explore example opens a bundled recording generated by the Rust replay engine.

Your file stays in this browser tab. Closing or clearing the tab removes the loaded recording. Files are limited to 10 MiB and 20,000 records; each run and metric has its own stream.

This workspace inspects recorded evidence. It does not connect to a live monitor, execute actions, or verify cryptographic authenticity.
